# Aero Ravens website

The site for Aero Ravens, Canyon Crest Academy's drone team, live at **[aeroravens.org](https://aeroravens.org)**.

## How this repo is laid out

| Path | What it is |
| --- | --- |
| `web/` | The site's source code (React + TypeScript + Vite). Edit things here. |
| `images/` | Original, full-size club photos. The site never links to these directly. |
| `index.html`, `assets/`, `media/`, `favicon.png`, `apple-touch-icon.png`, `og-image.jpg` | The **built** site that GitHub Pages serves. Generated by `npm run publish`, so don't edit these by hand. |
| `CNAME`, `.nojekyll` | GitHub Pages settings for the custom domain. |

## Making changes

You need Node.js 20 or newer.

```bash
cd web
npm install
npm run images     # first time only: makes the resized photos in web/public/media
npm run dev        # preview at http://localhost:5173
```

- **Text, results, meeting info, links:** `web/src/data/site.ts`, plus the section files in `web/src/components/`.
- **Photos:** `web/src/data/photos.json` lists every photo the site uses: its file in `images/`, alt text, caption, date, and crop focus (`pos`). Set `"gallery": true` to show a photo in the gallery.

To add a photo:

1. Put the original in `images/`.
2. Add an entry to `web/src/data/photos.json`.
3. Run `npm run images` to make the resized web versions.

## Publishing

```bash
cd web
npm run publish    # builds the site and copies it to the repo root
cd ..
git add -A && git commit -m "Update site" && git push
```

GitHub Pages serves the repo root of `main`, so the push is the deploy.
